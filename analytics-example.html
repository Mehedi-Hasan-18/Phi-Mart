🔍 PhiMart Analytics Integration

Vercel Web Analytics + Django API Backend

📊 What is Vercel Web Analytics?

Vercel Web Analytics provides real-time insights into your application's performance and user interactions. Track:

✓ Page views and traffic patterns

✓ Core Web Vitals (LCP, CLS, FID)

✓ Geographic data and device information

✓ Custom events and user interactions

🚀 Installation

For your frontend application:

npm install @vercel/analytics
Node.js required

⚡ Quick Start

For Next.js:

import { Analytics } from '@vercel/analytics/react'; export default function App() { return ( <> <YourComponent /> <Analytics /> </> ); }

For Plain HTML:

<script defer src="/_vercel/insights/script.js"></script>

🔗 API Integration

This is the PhiMart Django REST API backend. To track analytics:

1. Create or connect a frontend application (React, Next.js, Vue, etc.)

2. The frontend communicates with this API via REST endpoints

3. Add Vercel Analytics to the frontend to track user interactions

4. View metrics in your Vercel Dashboard
